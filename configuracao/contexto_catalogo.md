# Catálogo do Portal DTI Pesquisa (SDPESQ) - como estava no período analisado

Os tipos de requisição (request types) e as descrições abaixo são os reais do
portal SDPESQ da DTI Pesquisa FGV, no período coberto pelo histórico de chamados
(2024 a 2026). A organização em grupos lógicos reconstrói a estrutura de
navegação do portal nesse período (o portal já foi reorganizado depois desta
análise). Cada grupo reúne os chamados que faziam sentido juntos para o
solicitante; cada chamado é um request type real do portal, e a descrição é a
exibida ao usuário.

Estão listados os 17 request types analisados, observados no histórico de
chamados depois de excluir os serviços atendidos por outras equipes (última
seção).

## Grupo: Nuvem Pública (AWS, Azure, GCP)
| CRT (chamado) | Descrição exibida ao usuário |
|---|---|
| Solicitar serviços em nuvem | Requisições em nuvem. |
| Dúvidas sobre produtos da nuvem | Dúvidas ou solicitação de suporte sobre produtos da nuvem. |
| Análise de custos de nuvem | Auxílio em análise de consumo e budget de nuvem, assim como registros de consumo para encaminhamento para pagamento. |
| Persona de acesso a nuvem | Uma persona é um grupo de acessos que representam um perfil de negócio, por exemplo "cientista-de-dados". Neste chamado é possível criar/modificar Persona e/ou incluir/excluir pessoas que farão parte desse perfil. |

## Grupo: Servidores Acadêmicos e Recursos Computacionais
| CRT (chamado) | Descrição exibida ao usuário |
|---|---|
| Solicitar recursos computacionais para pesquisas | Solicitar avaliação e implementação de infraestrutura computacional para projetos de pesquisa e consultoria, contemplando aderência à LGPD. |
| Acessar pastas de dados de pesquisa | Ajustar acesso à pasta de dados em servidor de pesquisa. Pode-se requisitar acesso para novos usuários, além de alterar ou excluir acessos. Os pedidos devem ser feitos pelo ponto focal do projeto de pesquisa. |
| Instalação de pacotes em servidores acadêmicos (bibliotecas compartilhadas) | Utilize este formulário para solicitar a instalação de pacotes em servidores acadêmicos. Certifique-se de preencher todos os campos obrigatórios para garantir que sua solicitação seja processada corretamente. |

## Fora da análise (visível no portal, atendido por outra equipe)

Serviços que apareciam no portal para o pesquisador encontrar, mas são atendidos
por outras equipes. Ficam fora da descoberta, da otimização, das métricas e do
ranking, e foram removidos do universo analítico antes do Stage 1 por regra exata
sobre o Customer Request Type. O universo analisado passou de 1.584 para 1.456.

| CRT (chamado) | Chamados no período | Observação |
|---|---|---|
| Solicitação de Acesso a Bases de Dados | 128 | atendido pela equipe de Banco de Dados |

Também constam da lista de exclusão, mas sem nenhum chamado no período analisado
(família Sala de Sigilo / operações de dados confidenciais): Extração de
Resultados; Solicitação de Instalação de Base de Dados / Upload de Script na Sala
Sigilo; Solicitação de Instalação de Software; Solicitação para Agendamento;
Solicitação para Compartilhamento de Pasta de Trabalho.
