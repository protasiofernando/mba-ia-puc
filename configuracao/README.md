# Configuração institucional

Entradas versionáveis compartilhadas pelo pipeline operacional, dashboard e
geradores de pacote:

- `projeto.json`: identidade do projeto e padrão de nomes dos CSVs;
- `config_portfolio.json`: contexto, restrições e categorias obrigatórias;
- `contexto_catalogo.md`: catálogo real informado pela área.

Os CSVs continuam em `../data/` e não são versionados. A decisão curada não é
uma configuração: fica em `../formacao_portfolio/decisao_curada/`.
